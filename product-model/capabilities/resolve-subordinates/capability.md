# Resolve subordinates

Read one Garant ODT subordinate act, bind its document group from the kind the
operator names (a resolution or an order), collect its punkt units, mint
fixture component identities for them, and resolve text versions on an effect
day derived from the date in the filename. Component identities minted here
are fixture identities, not registry identity; the hierarchy registry holds no
subordinate-act bindings.

A missing effect day is fail-closed: the report keeps the key and states the
skip reason instead of silent zeros.
