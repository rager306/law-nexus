# law-source/consultant — НАБОР ФИКСТУР, НЕ КОРПУС

**Статус:** fixture vault. Файлы остаются tracked, но каталог **не является источником корпуса**.

## Что здесь лежит

82 XML-документа КонсультантПлюс, отобранных вручную как **эталонные фикстуры**
для батарей M199/M204/M207/M209 (gold battery, контрпримеры, обзоры практики).
Плюс подкаталог `.deprecated/` (40 файлов) — он **выведен из индекса git**
(см. `.gitignore`) и остаётся на диске только как история.

## Чем это НЕ является

- **Это не полный корпус.** Полный корпус — `consru_export/consru_export/exports/`
  (43 785 файлов, включая `npa/` 916, `fas/` 30 399, `courts/` 5 667, `xml/` 6 803).
- **Документы здесь не дублируют корпус.** Проверено по sha256: пересечение
  = 0 файлов. Это отдельный отбор (обзоры ВС, постановления Пленума,
  «Список документов (5).xml», 44-ФЗ в одной редакции), которого в корпусе нет.
- **44-ФЗ здесь — одна редакция.** В корпусе — 118 редакций:
  `consru_export/consru_export/exports/npa/law_2013-04-05_44-fz/edition-NNNN_*.xml`.
  Для задач про редакции и темпоральность использовать корпус, не этот файл.

## Правила использования

1. **Для корпусных задач и замеров — корпус, не этот каталог.**
   Рекурсивный обход: `find consru_export/consru_export/exports -name '*.xml'`.
2. **Не глоббить `law-source/consultant/**` как корпус.** Каталог выглядит как
   корпус, но содержит 82 файла из 43 785.
3. **Ссылаться можно только на конкретный файл-фикстуру**, а не на каталог.
   Канонические фикстуры, на которые ссылается код:
   - `federalnyi-zakon-ot-05-04-2013-n-44-fz-...-f9c8ca4c.xml` (M209 S02/S04 батареи)
   - `Список документов (5).xml` (M006 канонический фикстур)
   - обзоры практики ВС/Пленума (gold battery M199/M207)
4. **Новая ссылка на каталог как на корпус — дефект.** Governor-проверка
   `law-source-fixture-guard` покрывает только маркер fixture vault в этом
   README (плюс состояние `.deprecated/` в `.gitignore`) — глоббинг каталога
   как корпуса она не замечает; такая ссылка остаётся дефектом, который
   ловится на ревью, по самому правилу 4.

## Почему каталог помечен

2026-09-26: агент глоббил `exports/npa/*.xml` (плоский glob, не рекурсивный),
получил 798 файлов вместо 916, не нашёл 44-ФЗ (он в подкаталоге, и его
edition-файлы не содержат «44-fz» в имени) и ушёл в этот каталог как в
«источник 44-ФЗ». Корпусные замеры были посчитаны на неполном множестве.
Этот README существует, чтобы ловушка не повторилась.
