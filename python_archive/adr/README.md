# Archived Python-specific ADRs

**Status:** Archived (M107-7xtx1c). Superseded by Rust-aware ADRs in `doc/adr/`.

These ADRs document Python-specific architectural decisions for the law-nexus
codebase as it existed M068–M106. They are preserved for historical context and
to inform the Rust migration (see `doc/adr/0004-rust-migration-decision.md`).

**Do NOT apply these ADRs to new Rust code.** Rust ADRs (`doc/adr/0004-*` onward)
govern new architectural decisions.
