# 4. Архитектурные ограничения

1. **consru_export — read-only**. Не копировать в `law-source/` массово (561 МБ).
   Тесты обращаются по пути, fixtures — точечно.
2. **Каталог — `catalog-links-20260814.sqlite`**. Не `catalog.sqlite` (устарел).
3. **sha256 integrity**: каждый XML сверять с каталогом перед использованием.
4. **Consid** — ключ связывания: `consultantplus://offline/ref=<TOKEN>`.
5. **C2hint overview** (`Обзор изменений`) не использовать как legislative event log.
6. **Мульти-edition**: один документ может иметь несколько `editions` (разные revision_date).
