# Review 27 — Сквозная программа разбора НПА: P0–P9, семантика, identity, temporal provenance и evidence control

Дата: 05.09.2026.
Reviewed repository revision: `06fe544d3228`.
Источник: совместный запрос владельца и LLM-assisted синтез текущего Rust runtime,
канонических PRD/ADR, M200–M202 evidence и внешнего prior-art.

Это **иммутабельный L0-источник** в смысле ADR-0024. Статус:
`authoritative: false`, lifecycle: `[diagnostic]`. Review не изменяет Product,
Requirements, ADR, temporal vocabulary, GSD lifecycle, R035/R070 или product
readiness. Любое принятие вывода требует отдельного human disposition, owning
ADR/PRD change, GSD execution и class-matched evidence.

## 1. Назначение

Сформировать управляемую долгосрочную программу repository-level разбора НПА:
от source decode и покрывающей токенизации до local grammar, document context,
semantic scoping, official identity claims, reference binding, NormRule IR,
temporal provenance, registry projection и evidence ledger.

Программа должна:

1. сохранить ортогональность document parsing, temporal legal state и
   evidence/readiness lifecycle;
2. не сглаживать candidate в fact, inherited в explicit, diagnostic в
   validated;
3. измерять прогресс на воспроизводимых corpus manifests;
4. фиксировать regressions, gaps и semantic corrections append-only;
5. управляться через GSD roadmap, а проверяться repository governor;
6. сохранить Rust-only product runtime; Python остаётся control-plane harness.

## 2. Executive verdict

Текущий P0–P9 контракт архитектурно пригоден как верхнеуровневая ось, но
runtime реализован неравномерно. Сильны covering lexer, literal LawRef capture,
immutable mention/binding distinction и typed temporal ядро. Главный разрыв —
между lexical capture и верхними normative/temporal моделями: отсутствуют
runtime `MorphEvidenceSet`, immutable local grammar frames, bounded whole-
document context, role-bearing semantic claims, ORG/GEO assembly,
coordinating lists и cross-block continuation.

Следовательно:

```text
implemented lexical evidence
    → [missing semantic bridge]
    → bounded normative/temporal capability
```

M200, M201 и M202 не закрывают этот разрыв:

- M200 — diagnostic/bounded measurement; `arbitrate_pair` и
  `on_candidate_limit` не подключены к `capture_lawrefs`;
- M201 — один provenance chain из 118 редакций; R070 остаётся active;
- M202 — fixture-sized hierarchy mapping 3/6; R035 остаётся active.

## 3. Каноническая layered model

Текущий порядок P0–P9 сохраняется:

```text
P0 complete-document decode
P1 structural index and requisites
P2 lex/morphology/local grammar
P3 literal mentions
P4 immutable analysis overlay
P5 bounded context closure
P6 semantic field claims and ThisRef
P7 proposed identity claims
P8 bindings and endpoint pairs
P9 evidence and diagnostics
```

Для реализации его следует раскрыть в слои:

| Layer | Responsibility | Current boundary |
|---|---|---|
| L0 | Provider decode + byte anchors | partial runtime |
| L1 | Structural index/requisites | partial runtime |
| L2 | Covering nine-kind `lex()` | implemented `[bounded]` |
| L3 | Morphological evidence alternatives | narrow/missing |
| L4 | Immutable local grammar frames | missing/proposed |
| L5 | Literal mention capture | implemented subset |
| L6 | Document context/coreference | missing/proposed |
| L7 | Semantic roles, condition, negation, exception | narrow/missing |
| L8 | Official identity claims | missing/proposed |
| L9 | Reference binding/endpoints | partial/smoke |
| N0–N3 | Normative assembly and abstention | upper model exists, text bridge missing |
| T0–T3 | Admission, NormativeState, edition delta | bounded runtime |
| E0–E3 | Evidence closure and publication | partial/proposed |

The private alphabetic `tokenize()` is transitional. It must not be silently
replaced or treated as equivalent to covering `lex()` until consumers are
migrated or the two views receive incompatible Rust types.

## 4. Orthogonal FSM contract

### 4.1 Document readiness

```text
raw → decoded → base_indexed → locally_analyzed → analysis_indexed
    → context_closed → projected → resolution_closed → evidence_emitted
```

A transition is legal only when every work item in the previous state has a
typed terminal outcome. `resource_limit`, `schema_drift`, `source_changed` and
provider decode failures are terminal failures, not empty success.

### 4.2 Mention lifecycle

```text
unseen → proposed → captured | rejected
```

A captured literal span cannot be mutated or deleted by failed context,
identity or binding.

### 4.3 Local grammar lifecycle

```text
no_frame → proposed → accepted_local | ambiguous | rejected
```

An accepted frame is source-local, immutable and bounded. Cross-block
continuation is an edge, never a widened source span.

### 4.4 Context dependency lifecycle

```text
not_evaluated → not_required
              | requested → queued → resolving
                  → sufficient | partial | conflicting | unavailable
                  | cycle | limit
```

Every request names a structural relation, role, key and traversal budget.
Model calls and unbounded semantic similarity are forbidden transition guards.

### 4.5 Semantic scope lifecycle

```text
lexeme_detected → construction_proposed → scoped → qualified
```

Typed failures include `unscoped_actor`, `unscoped_action`,
`unscoped_negation`, `unscoped_condition` and `conflicting_scope`.

### 4.6 Identity lifecycle

```text
fields_proposed → compatibility_checked → identity_claim_proposed
                → admitted | incomplete | conflicting | rejected
```

The parser proposes evidence-bearing fields and identity claims; it does not
mint canonical Work/Expression identity.

### 4.7 Binding lifecycle

```text
unattempted → candidate_ready → resolving
            → resolved | unresolved | conflicting | rejected
```

Resolution outcome and record lifecycle (`proposed/confirmed/rejected/
superseded`) are different axes.

### 4.8 Normative and temporal lifecycles

```text
textual_construction → role_scoped → condition_scoped → exception_scoped
                     → norm_rule_candidate → evaluable | abstaining

delta_proposed → evidence_admitted → envelope_constructed
               → transition_eligible → edition_delta_emitted
```

`Satisfied` does not imply `Applicable`. Publication date and filename do not
establish legal effect.

## 5. Mandatory semantic rules

1. Negation is a scoped legal property, not a boolean inversion of a lexeme.
2. Condition and subjunctive content are preserved; they are not dropped as
   “not a fact”.
3. Exceptions and carve-outs that cannot be scoped force `partial` or
   abstention.
4. Coordinating act lists use explicit frame members and bounded TYPE
   inheritance.
5. Decimal legal designations are structural paths, not arithmetic ranges.
6. ORG, GEO and ADDRESS are separate claims.
7. `CurrentDocumentRequisites` is an explicit derived claim. Conflicting head,
   filename and catalog evidence remains conflict.
8. Every inherited field carries a derivation path to explicit evidence.
9. Ambiguity, conflict and limits never select a silent winner.
10. Prompt/LLM output is annotation or triage only and cannot drive a product
    FSM transition.

## 6. Prior-art boundary

- Pullenti Lingvo 4.34: NC/commercial prior-art only. Adopt patterns for slot
  alphabets, local grammar, coordinating lists, ThisDecree-style context,
  ORG/GEO separation and endpoint expansion. Do not use it as runtime,
  dependency, gold, N2 rater or `lex()` backend.
- RCO Fact Extractor SDK: proprietary prior-art. Transferable ideas are
  role-bearing frames, morphology alternatives, coreference before assembly,
  versioned resources, modality/polarity and operational SLOs. Integration
  requires an explicit owner/licensing decision.
- `Koziev/rutokenizer`: GPL-3.0. No code copying or translation. Only clean-room
  black-box differential cases and independently implemented contracts are
  allowed.

## 7. Corpus and metric model

Authoritative full-corpus source:
`consru_export/consru_export/exports/` — 43,785 XML files. `law-source/` is a
fragment/provider fixture source and cannot support full-corpus claims.

| Stratum | Purpose | Maximum claim |
|---|---|---|
| C0 tracked fixtures | unit/contract | `[smoke]` |
| C1 hostile synthetic | fail-closed paths | `[bounded]` |
| C2 frozen bounded sample | development metrics | `[bounded]` |
| C3 provider/year/type holdout | generalization | holdout-confirmed |
| C4 full corpus diagnostic | drift/bounds/performance | `[diagnostic]` |
| C5 double-coded legal gold | quality validation | `[validated]` after gate |

Every metric receipt must bind:

```text
parser revision + corpus manifest version + corpus snapshot hash
+ provider strata + environment + exact/estimated/proxy classification
```

Critical zero-tolerance counters on hostile/gold contours:

```text
source_byte_loss
silent_skip
false_identity_mint
filename_derived_temporal_effect
unresolved_to_resolved_smoothing
condition_or_negation_dropped
captured_mention_mutated
silent_conflict_merge
```

Layer metrics include decode error counts, 100% lexer covering, morphology
ambiguity, frame exact/containment F1, context terminal distribution,
condition/negation scope accuracy, identity false-positive rate, binding
false-link rate, NormRule trace completeness, provenance completeness,
deterministic replay, throughput and peak RSS.

Provisional thresholds are baselines, not authority: simple citation exact F1
0.95, complex list/range exact F1 0.85, coreference CoNLL F1 0.80, semantic
role macro-F1 0.85, false binding at most 0.5%, performance regression block
above 10% on the same manifest/environment. These thresholds require a
separate policy disposition before enforcement.

## 8. Durable control artifacts

The program requires four append-only ledgers:

1. `parsing-metrics-history.jsonl` — source-bound comparable measurements;
2. `parsing-regression-ledger.jsonl` — baseline/candidate delta, severity,
   resolution and verification;
3. `parsing-gap-ledger.jsonl` — stable codes by owning layer;
4. `semantic-correction-ledger.jsonl` — superseding semantic contract changes,
   ADR, migration and replay delta.

Stable gap prefixes:
`DEC`, `STRUCT`, `LEX`, `MORPH`, `GRAM`, `MENT`, `CTX`, `ROLE`, `ID`, `BIND`,
`NORM`, `TEMP`, `PROV`, `TABLE`, `CORP`, `GOV`.

Ledgers store hashes and bounded anchors, not raw legal corpus text.

## 9. Long-horizon execution order

1. Control baseline: review disposition, corpus manifest, schemas, ledgers,
   governor no-op/freshness/promotion guards.
2. Token boundary and runtime bounds: explicit dual views, clean-room hostile
   tokenizer suite, wire arbitration and ceiling into capture.
3. Immutable local grammar: coordinating act lists and structural ranges only.
4. Bounded document context: structure index, analysis overlay, worklist,
   cycles/limits, continuation edges.
5. Semantic scoping: actor/action/object, polarity, condition, exception and
   temporal qualifier.
6. Identity and binding: semantic field claims, ORG/GEO, official identity
   claims, ADR-0019 resolver and endpoints.
7. Temporal vertical slice: XML → mention → binding → event → provenance →
   NormativeState → EditionDelta → checkout.
8. Gold and provider expansion: 100→400→800 double-coded items, Garant holdout,
   tables/appendices as separate contours.
9. Promotion: only after repeated holdout/gold runs and current source-bound
   evidence.

## 10. Governor CLI control contract

Canonical invocation:

```bash
uv run python -m law_nexus_harness governor
```

`uv run python -m law_nexus_harness.governor` must never remain a silent no-op;
it must fail with exit 2 and canonical remediation or delegate explicitly.

Required additive groups/checks:

```text
parsing/parsing-fsm-transition-completeness
parsing/parsing-layer-schema-compatibility
parsing/parsing-metric-regression
corpus/corpus-source-authority
corpus/corpus-manifest-freshness
lifecycle/lifecycle-promotion-guard
semantic/semantic-condition-negation-preservation
semantic/semantic-no-silent-dedup
semantic/semantic-no-identity-mint
temporal/temporal-no-filename-inference
vendor/vendor-license-boundary
evidence/evidence-source-hash-current
evidence/generated-registry-authority
```

Governor does not parse the 3.7 GB corpus and does not create facts or
identities. Rust commands produce bounded receipts; governor checks schemas,
hashes, source authority, lifecycle gates, drift and regression thresholds.

Every failure must report `check_id`, group, severity, observed, expected,
remediation and tracked evidence anchors. Exit classes: 0 success, 1 policy or
validation failure, 2 tool/configuration failure. A stale generator test must
invoke the product command with `--check`; write mode cannot prove stale
rejection.

## 12. Findings for disposition

### RC27-F01 — Semantic bridge absent

**Severity:** blocking for parser-readiness promotion.
**Finding:** lexical capture is not connected to role-bearing semantic and
normative assembly.
**Required action:** implement L4/L6/L7 in the ordered bounded slices above.

### RC27-F02 — Bounds helpers are unwired

**Severity:** blocking for production protection claim.
**Finding:** M200 arbitration/ceiling helpers are tested but not in
`capture_lawrefs`.
**Required action:** wire them with typed terminal diagnostics and hostile
coverage.

### RC27-F03 — Dual token streams are an untyped seam

**Severity:** high.
**Finding:** private `tokenize()` and covering `lex()` can be confused by
consumers.
**Required action:** inventory consumers, migrate or assign incompatible typed
views; no blind replacement.

### RC27-F04 — Local grammar is missing

**Severity:** high.
**Finding:** coordinating lists, structural multi-value ranges and inherited
TYPE are proposed patterns, not runtime capability.
**Required action:** begin with exactly two immutable bounded frame types.

### RC27-F05 — Document context is missing

**Severity:** high.
**Finding:** no bounded deterministic whole-document worklist exists for
ThisRef, continuation and inherited requisites.
**Required action:** implement typed request/outcome FSM before identity work.

### RC27-F06 — Modality scope is incomplete

**Severity:** high.
**Finding:** negation/condition/exception cannot currently support legal
semantic assembly.
**Required action:** preserve scope and abstain on incomplete constructions.

### RC27-F07 — Identity and resolver boundary incomplete

**Severity:** blocking for registry promotion.
**Finding:** official identity claims, ORG/GEO and full ADR-0019 resolver are
absent/partial.
**Required action:** preserve candidate/fact separation and zero false mint.

### RC27-F08 — Provenance remains one-edition bounded

**Severity:** blocking for R070.
**Finding:** one tracked edition out of 118 does not establish coverage.
**Required action:** staged edition manifests and evidence-backed deltas;
unresolved stays explicit.

### RC27-F09 — Registry mapping remains fixture-sized

**Severity:** blocking for R035.
**Finding:** 3/6 admitted candidates and legacy rows do not establish corpus
ontology capability.
**Required action:** satisfy named R035 proof gates before promotion.

### RC27-F10 — Corpus claims need stable manifests and gold

**Severity:** high.
**Finding:** full diagnostic scans measure drift/bounds, not semantic quality.
**Required action:** C2/C3 manifests and C5 double-coded gold.

### RC27-F11 — Regression and correction memory is not durable enough

**Severity:** high.
**Finding:** no unified append-only metric/regression/gap/correction chain owns
parser evolution.
**Required action:** versioned schemas, receipts and governor checks.

### RC27-F12 — Governor must become the enforcement surface

**Severity:** high.
**Finding:** canonical CLI exists, but parsing/corpus/lifecycle checks and
silent dotted-module protection are incomplete.
**Required action:** additive checks, actionable diagnostics and v2-compatible
report fields; governor remains non-product control plane.

## 13. Rollback and stop criteria

Rollback a slice when any of the following occurs:

- critical zero-tolerance semantic counter becomes non-zero;
- output schema changes without owning ADR/migration;
- new corpus source lacks license/authority classification;
- exact metric is replaced by proxy/estimate without label;
- performance regresses beyond accepted same-manifest threshold;
- a failure path becomes silent success;
- `[diagnostic]`, `[proposed]` or `[bounded]` is promoted without current proof;
- R035 or R070 is closed from documentation or fixture-only evidence.

`deferred-undefined` and `runtime deferred` are hard stops, not backlog labels
that execution may fill by inference.
