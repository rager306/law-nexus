# 5. Модель: temporal AST каждого нормативного акта со связями

## 5a. Один акт — пять слоёв одной AST

```text
Work (44-ФЗ «О контрактной системе», стабилен)
 │
 ├─ Expression @ legal_act_effect_day (ред. от 28.12.2025)
 │    ├─ CompositionAst(t) = fold(membership_events ≤ t)         ✅
 │    │     Razdel → Glava → Statya → Chast → Punkt → Podpunkt
 │    ├─ EditionAst(t)     = filter(CompositionAst, presence ≤ t) ✅
 │    ├─ TextAst(t)        = resolve_ctv(cc, t)                   ✅ prototype
 │    └─ ForceOverlay(t)   снаружи дерева (ADR-0018)              ✅ S2-S3
 │
 ├─ Manifestation = EditionOracle (WordML/ODT = наблюдение)        ✅
 │
 └─ AmendmentEvent = n-ary причина (кто / что / когда / op / грани)
      ├─ facet: structural  (attach/detach)                        ✅
      ├─ facet: industrial  (renumber/move/split/merge)            ✅
      ├─ facet: text        (CTV wording)                          ✅ prototype
      └─ facet: force       (NormativeEffect)                      ✅ S2
```

**Oracle check**: `drift(t) = fold(events, t) Δ snapshot(oracle@t)`        ✅
**Heal**: drift ≠ 0 → new event or waiver (не ластик по дереву)            ❌ R6-03
