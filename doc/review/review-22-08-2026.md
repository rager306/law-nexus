# Review 11 — Ссылочная лента слота; аудит пробелов; кросс-дисциплинарные паттерны

Дата: 22.08.2026. Опора на HEAD `336be5de3a908e7d3e9580224695b48a5609539c`
и на чат-итерацию после Review 10 (`doc/review/review-21-08-2026.md`).

Это **иммутабельный L0-источник** (ADR-0024): фиксация **одной итерации** —
ссылки норм как четвёртая лента слота, плюс аудит того, что модель ещё не взяла
у de Martim v5 и европейских стандартов, плюс поиск паттернов вне юриспруденции.
Текст **не утверждён** как канон, не закрывает TSG-012 / TQ-05, не повышает
lifecycle ADR, не чеканит Rust-типы, не двигает `fsm.current` / O3 / TSG-017 S4
и не является пакетом Review Case.

Связь с Review 10: пакет C1 как commit, четыре полки
(состав/текст, сила, переходные, применимость), active/passive modification,
repeal без удаления слота — остаются. Эта итерация **добавляет ленту ссылок**
и запрещает считать лексический mention citation authority.

Инжект M001 (FalkorDB / GraphBLAS / «WordML нельзя, пока не доказан 44-fz.odt»)
к этой модели **не применяется**. Живой канон: ADR-0009, 0016–0023, D046
(ядро владеет смыслом; ELI/AKN/LRMoo/LKIF/MetaLex/LegalRuleML — compatibility).

# 1. Что фиксирует эта итерация (простым языком)

**Ссылка — не подстрока и не гиперссылка Консультанта.**
Это факт на слоте: кто на кого указывает, каким видом речи, динамически или
замороженно, в каком интервале жизни формулировки источника.

Без этой ленты машина времени Review 10 собирает текст ст. 93 на дату `t`
и молчит: куда вела отсылка, жива ли цель, это тот же Work или чужой,
динамическая «действующая 31» или static «31 в редакции такого-то ФЗ».

Три фазы, парсер закрывает только первую:

```text
1. Кандидат (mention)     — лексика / hyperlink / диапазон «ст. 53–59»
2. Биндинг к личности     — слот (wId/CC) того же или другого Work
3. Checkout на дату t     — join состава + CTV + силы источника и цели
                            или typed non-success
```

На HEAD есть фаза 1 `[bounded]` (`ReferenceMention`, `RawLink`) и словарь
рёбер YAML (`cites` / `amends` / …) плюс конструкторы `amends` 138/333.
Фазы 2–3 = **TSG-012 / TQ-05**, runtime нет. `cites` не повышает силу
(ADR-0019); резолвер должен это запретить тестом, не прозой.

# 2. Прогресс модели нормативного акта (Reviews 9 → 10 → 11)

| Итерация | Что стало first-class | Что ещё дыра |
|---|---|---|
| Review 9 | WALK-S / WALK-I; семя ≠ C0; CC растёт от первого oracle | WALK-T ещё Mode B (Δ сводок) |
| Review 10 | WALK-T = C1-пакет на семя; слот вечен; абзац = список; repeal = detach+Repealed; active/passive; четыре полки | ссылка = подстрока; нет резолвера на t |
| **Review 11** | **четвёртая лента слота = cites**; dynamic vs static; внутренние / исходящие / входящие — одно ребро; wId≠eId | фазы 2–3; перенумерация как first-class для ссылок; входящие честно неполны без корпуса |

Ленты одного слота после этой итерации:

```text
личность   — вечный слот / CC (AKN wId)
состав     — attach/detach на t
текст      — CTV / список абзацев родителя
сила       — InForce / Repealed / …
переходные — оверлей ADR-0021, не воскрешение слота
ссылки     — исходящие и входящие cites, сами с датами   ← NEW
```

Применимость (ADR-0023) по-прежнему **не** лента этой машины.

# 3. Канон идеи ссылки (не ADR)

## 3.1 Ребро

```text
from:     слот-источник + CTV, в котором жива фраза-отсылка
to:       слот-цель того же Work ИЛИ слот другого Work
kind:     cites  (implements / specifies — позже, YAML уже знает имена)
mode:     dynamic → цель = слот, версию берём на t запроса
          static  → цель = слот + зафиксированный CTV/дата
when:     ребро рождается и умирает вместе с CTV источника
evidence: пакет C1 или семя; hyperlink = hint фазы 2, не канон
```

`amends` / `repeals` / `corrects` **не** кладутся в ленту ссылок.
Это грамматика правки (Review 10, ELI 1.1/1.4).

## 3.2 Резолвер на t (TL-GC10)

```text
1. CTV источника на t. Нет фразы — ребра нет.
2. dynamic: checkout цели на тот же t (состав + CTV + сила).
3. static: checkout зафиксированного снимка, latest запрещён.
4. Typed non-success, не пустая дыра:
     UnknownTarget | Ambiguous | RepealedTarget | DetachedTarget
     | OutOfCorpus | HyperlinkOnly
```

Hostile twin: «взять последнюю редакцию цели».

## 3.3 Три направления — одна модель

| Направление | Концы | Честность покрытия |
|---|---|---|
| внутренние | два слота одного Work | волна 1 резолвера |
| исходящие внешние | слот A.Work → слот B.Work | `OutOfCorpus`, пока B нет в графе |
| входящие | обход `cited_by` | нет в корпусе ≠ «никто не ссылался» |

Ссылка на статью ≠ ссылка на все её части. Цель = названный слот.
Диапазон «статьи 53–59» = пачка рёбер (AKN `rmod`), не один узел.

## 3.4 Жёсткие случаи

1. Цель Repealed, источник жив → ребро живёт; checkout цели: слот есть,
   в составе нет, сила Repealed, последний CTV для цитаты истории. Не 404.
2. Источник изложили, фразу выкинули → старое ребро закрыто датой изложения.
3. Перенумерация → wId держит личность; человеческий номер — ярлык CTV.
4. Абзацный сдвиг → биндинг через список родителя **на дату источника**.
5. Цель ещё не minted → `UnknownTarget` до появления слота.
6. Внешний акт не в корпусе → `OutOfCorpus`. Не собирать ГК из consid.
7. «Законодательство РФ» / «в установленном порядке» → не биндить (`Ambiguous`).

Русская доктрина по умолчанию ближе к **dynamic** (Work-IRI), пока текст сам
не заморозил редакцию («в редакции ФЗ от …»). Это правило профиля, не хардкод
44-ФЗ.

## 3.5 Развилки (не закрыты)

| ID | Развилка | Рекомендация итерации | Альтернатива |
|---|---|---|---|
| F11-A | mode по умолчанию | dynamic, static только при явной заморозке | не биндить mode → больше `Ambiguous` |
| F11-B | волна 1 резолвера | только внутренние одного Work | сразу междеревья (без ГК честного ответа нет) |
| F11-C | Repealed-цель | два режима запроса: цитата истории = успех с пометкой; «действующая норма» = `RepealedTarget` | одна политика на все запросы — ломает одну из сторон |

## 4.2 ELI 1.4–1.5 — ссылки как граф законов, не как XML

| Паттерн | Суть | У нас | Вердикт |

## 4.3 Akoma Ntoso — динамическая ссылка и два имени

Спецификация Naming Convention (нормативная для level 2):

> Цель ссылки в законодательстве — **не** исходная и **не** текущая редакция,
> а версия, действовавшая **в момент дела**. Ссылки **динамические**:
> цель едет во времени. Поэтому section 35 во всех версиях имеет **один**
> идентификатор, **даже после перенумерации**.

| Паттерн | Суть | У нас | Вердикт |
|---|---|---|---|
| **wId** vs **eId** | личность Work vs позиция в этой XML-редакции | слот vs якорь абзаца на дату | **взять жёстко**: резолвер бьёт в wId; eId сводки — не канон |
| Master Expression | версия, где wId и eId ещё совпадали; после расхождения wId заморожен | не названо | **взять имя**: «мастер-снимок слота» = редакция, от которой ведётся wId при перенумерации |
| Virtual expression | IRI с датой = точка-во-времени без отдельного файла | checkout на t | паритет |
| Work-IRI vs Expression-IRI | dynamic vs static | mode §3 | паритет |
| Сценарий перенумерации (act Y art.2 → art.15; новый art.2) | старая dynamic-ссылка на art.2 должна попасть в **тот же** wId, теперь с номером 15; новая ссылка на art.2 — **новый** слот | Review 10 знает `mv` слота; **резолвер ссылок это не использует** | **дыра**: без wId две ложные цели |
| activeModifications / passiveModifications | в поправке и в изменённом | Review 10 | паритет; не XML-store |
| `<mod>` / `<mmod>` / `<rmod>` | одна / пачка / диапазон | пакет C1 | взять типы пачки и диапазона для cites тоже |
| `<quotedText>` vs `<quotedStructure>` | вычеркнуть слова vs изложить структуру | речевые акты | паритет |
| `refersTo` на онтологический концепт | ссылка не только на текст, но на TLCConcept / TLCPerson | нет | **не в волну 1**; иначе склеим слот и «понятие закупки» |
| XML как истина редакции | версия = документ | отвергнуто Review 10 | **не брать** |

**Главный долг vs AKN:** перенумерация + dynamic reference. 44-ФЗ редко
перенумеровывает статьи; кодексы — да. Профиль не должен это запрещать,
иначе резолвер соврал на первом ГК.

## 4.7 Непрерывность и дискретность (стандарты это знают, мы смазали)

Закон кажется непрерывным текстом; изменения — **дискретные события**.
Между событиями состояние **постоянно** (piecewise constant).

| Что дискретно | Что непрерывно (на интервале) | Риск, если склеить |
|---|---|---|
| AmendmentEvent, mint слота, repeal | CTV, состав, сила, ребро cites | хранить «ежедневный снимок» 44-ФЗ как истину |
| Смена номера при `mv` | wId | резолвер по номеру на чужой дате |
| Появление/исчезновение фразы-отсылки | само ребро на своём interval | cites как вечное свойство статьи |
| Смена силы (InForce→Repealed) | последний CTV | удалить текст вместе с силой |

de Martim: validity interval **открыт**, пока нет terminating event —
это и есть непрерывность между дискретными ударами. AKN virtual expression
— непрерывный запрос к дискретному логу. Мы это подразумеваем checkout'ом,
но не сказали: **канон = event log; snapshot = кэш**. Сводка «ред. от»
притворяется непрерывной истиной — отсюда Mode B.

Ссылка добавляет вторую дискретность: ребро живёт, пока жив CTV *источника*,
независимо от ударов по *цели*. Два независимых точечных процесса на одном
запросе.

| Формула | Кандидат kind | Не делать |
|---|---|---|
| «в соответствии со ст. 31» | `cites` dynamic | обязанность |
| «если иное не предусмотрено ст. X» | `cites` + условие-исключение | applicability-решение |
| «в редакции ФЗ от …» | `cites` static | latest |
| «статьи 53–59» | пачка `cites` | один узел |
| «в порядке, установленном Правительством» | `refers_to` без цели-слота / `OutOfCorpus` | выдумать ПП |
| «законодательство о контрактной системе» | не биндить | псевдо-Work |
| 138-ФЗ «изложить ст. 31» | `amends` | cites |
| hyperlink consid | Manifestation hint | identity |

Волна 1 резолвера может закрыть только распознанные внутренние `cites`.
Остальное — честный `Ambiguous` / `OutOfCorpus`, не «умная» догадка.

# 5. Взгляд с необычной стороны

Не метафоры «для красоты». Каждая аналогия либо даёт операцию, которой нет,
либо запрещает соблазн, который у нас уже всплывал.

## 5.1 Математика

**Слой как расслоение (fiber bundle).** База = вечные слоты (пространство имён
Work). Слой над точкой = (состав, CTV, сила, ссылки) на дату t. Checkout —
сечение базы на t. Сводка Консультанта — одно сечение, выданное за базу.
Ссылка dynamic — морфизм баз (слот→слот), поднятый в слой только при запросе.
Static — морфизм уже в слое (CTV→CTV). Перенумерация — автоморфизм базы
(`mv` wId), не смена слоя.

Что даёт: запрет хранить «номер статьи» как id базы; номер — координата в
одной карте, wId — точка.

**Событийный лог как образующие группы преобразований.** Каждая микрокоманда
C1 — образующая; checkout — произведение образующих с эффектом ≤ t
(моноид, не группа: repeal не обязан иметь гладкий inverse в тексте, только
в истории). Некоммутативность очевидна: «изложить, потом исключить абзац» ≠
наоборот. Это уже rebase Review 10; ссылка добавляет **сопряжение**:
преобразование цели не переписывает ребро, пока не ударили по источнику.

**Граф ссылок как отдельный комплекс, фильтрованный временем.** Не свойство
вершины «список href», а 1-цепи с носителем-интервалом. Тогда «кто ссылался
на 59 в 2020» — ограничение комплекса на t, не обход вечных рёбер.
Входящие без корпуса = дырявый комплекс; дыру надо маркировать, не заполнять.

**Типизация неуспеха как сумма типов, не Option.** `UnknownTarget | Repealed | …`
— coproduct. Склеить в `None` = потерять, *почему* нет цели. Это уже сказано
прозой; математика требует, чтобы резолвер **не** имел пути в «пустую ссылку».

## 5.2 Физика

**Worldline vs snapshot.** Слот — мировая линия в пространстве-времени
(путь CC × время). CTV — событие на мировой линии (дискретная вспышка
изложения). Checkout — пространственноподобное сечение «все слоты на t».
Сводка «ред. от» — фото пластины, не траектория. Repeal — линия не
уничтожается, она выходит из конуса «состав»; цитата истории = вдоль линии
назад.

**Два времени, как в теории относительности нельзя сложить в одно.**
Valid time и transaction time — разные оси (de Martim bitemporal; ADR-0009).
Ссылка dynamic синхронизируется по **valid** цели с **valid** источника.
Путать с датой файла XML = смешать системы отсчёта.

**Запаздывающий потенциал / световые конусы.** Событие 476-ФЗ на дате
подписания ещё не «видно» силе ст. 59, пока не наступил effect-clock
(01.01.2022) и не сработала кнопка. Ссылка, написанная в 2021, не должна
«знать будущее» цели, если mode dynamic на дату *дела* 2021. Каузальность:
резолвер на t не читает события с effect > t. Это тривиально для текста и
легко нарушить для cites, если подтянуть latest.

**Фазовый переход vs плавная деформация.** Repeal / mint / `mv` — фазовые
переходы состава. «Изложить» — деформация текста при том же слоте. Нельзя
интерполировать между редакциями («средняя ст. 31»). Закон кусочно постоянен;
между ударами — вакуум изменений, не градиент.

**Закон сохранения «заряда» личности.** wId не создаётся изложением и не
уничтожается repeal. Создаётся mint, уничтожается только ошибка модели
(антипаттерн «вычистить узел 59»). Ссылка — ток между зарядами; ток может
течь к уже «нейтральному» (Repealed) заряду, иначе история входящих умрёт.

## 5.3 Биология

**Генотип / фенотип.** wId+слот = генотип (идентичность статьи 31).
CTV = фенотип на дату. Среда (переходные, профиль) меняет *выражение*
без смены гена. LLM, читающий только фенотип latest, — как селекционер,
который считает, что вымерший вид «не существовал».

**Ортолог vs паралог.** После перенумерации art.2→art.15 тот же ген
(ортолог, wId). Новый art.2 — дупликация/вставка (паралог, новый слот).
Ссылка по имени «art.2» без даты = спутать ортолога с паралогом.
Биоинформатика решает это **стабильным id гена**, не символом в последнем
геноме. Это ровно AKN wId.

**Горизонтальный перенос генов.** Внешняя ссылка 44-ФЗ → ГК — не наследование
внутри дерева 44-ФЗ. Это HGT: ребро между геномами. Класть ПП ребёнком в
AST 44-ФЗ (запрет R4-07) = принять горизонтальный перенос за вертикальный.

**Апоптоз, не некроз.** Repeal — запрограммированная гибель клетки:
слот остаётся в ткани как тело (последний CTV), вынут из функции.
Удалить узел = некроз, рвёт входящие синапсы (cites). Переходные —
«клетка ещё работает в этой ткани до даты», не воскрешение.

**Незрелый транскрипт.** Кандидат `ReferenceMention` — pre-mRNA. Биндинг —
сплайсинг до зрелой изоформы (слот). Hyperlink consid — поли-А хвост
провайдера, не CDS. Повышать mention до citation authority = транслировать
интроны.

## 5.4 Химия

**Реакция vs соединение.** C1-пакет — реакция (реагенты, условия, катализатор-
кнопка «после ПП», стехиометрия микрособытий). CTV — соединение-продукт.
Сводка «ред. от» — спектр продукта, не уравнение реакции. Mode B Review 9
пытался восстановить уравнение по двум спектрам — это спектроскопия без
механизма, всегда недоопределено.

**Комплекс vs ковалент.** `cites` — координационная связь: источник «держит»
цель, цель не входит в молекулу источника. `is_part_of` / WALK-S — ковалент
внутри молекулы. `amends` — реакция, меняющая продукт. Склеить cites с
part-of = принять аддукт за новый скелет.

**Период полураспада / метастабильные состояния.** Vacatio legis — метастабиль:
закон уже «есть» (опубликован), продукт ещё не в основном состоянии силы.
Ссылка dynamic на дату внутри vacatio должна видеть *предыдущий* продукт
цели, не «молекулу, которая вот-вот появится», если effect-clock цели ещё
не тикнул.

**Каталог CAS vs структурная формула.** ELI URI / wId — регистрационный номер.
CTV — формула. Нельзя резолвить реакционную схему по торговому названию
«статья 31» без CAS и без даты партии.

## 5.5 Что из аналогий стоит *взять* в модель (короткий список)

1. **Канон = лог дискретных реакций/событий; сечение — кэш.** Уже дух Review 10;
   дописать явно для cites: ребро имеет носитель-интервал, не вечный href.
2. **wId как сохраняющийся заряд / ортолог / CAS.** Перенумерация не чеканит
   новый слот; новый номер при том же пути — другая карта.
3. **Каузальный конус резолвера.** На t не видно effect > t; latest = нарушение
   причинности.
4. **Coproduct неуспехов.** Запрет `None`.
5. **HGT ≠ дерево.** Внешние cites никогда не становятся детьми AST.
6. **Два независимых точечных процесса.** Удары по источнику закрывают ребро;
   удары по цели меняют checkout цели. Не один «update ссылки».
7. **Не интерполировать** редакции. Кусочно постоянно.

Чего **не** брать из аналогий: непрерывные поля, вероятностные амплитуды
(LLM similarity ≠ ребро), «энергия связи» как вес cites, биологическая
эволюция как лицензия додумать недостающий ГК.
