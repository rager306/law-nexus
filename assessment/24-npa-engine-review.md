## 1. Что ревьюировали

Материал владельца «Движок НПА: не клонировать razdel/mawo-razdel» +
проверка его утверждений по коду проекта и по открытым источникам
(API pravo.gov.ru, лицензии razdel/natasha/mawo/SynTagRus).

## 2. Подтверждённые факты

| Факт | Доказательство |
|---|---|
| Наш токенизатор alphabetic-only: «ст.» разваливается, «15.1»/даты/«№ 149-ФЗ» токенами не являются | `ln-decode/tokenizer.rs` (`is_alphabetic`, `to_lowercase`, без ё-нормализации) |
| Морфослой покрывает только статья ×8 / пункт ×10 + деонтику; глава/часть/подпункт/раздел — 0 форм в свободном тексте | `ln-decode/morphology.rs::classify`; иерархическая лестница — только именительные ×3 регистра (`decode_marker_prefixes`) |
| razdel/mawo — новостные split-then-rejoin; в НПА точка чаще не граница («ст. 15.1», «от 27.07.2006», «№ 149-ФЗ», «в ред.», перечни «1.» / «а)», «;» = граница пункта) | материал владельца + практика 44-ФЗ |
| Лицензии: razdel/natasha/mawo — MIT; SynTagRus — CC BY-NC-SA (нельзя в коммерческий бинарь) | тексты лицензий |
| Официальный API pravo.gov.ru существует: `publication.pravo.gov.ru` — read-only JSON (`PublicBlocks`, `Categories`, документы/файлы) + RSS + PDF | страница help портала; рабочие n8n-потоки (RSS+PDF) |
| Сторонние датасеты могут нести CC-BY-SA — брать из официального источника | data.apicrafter (CC-BY-SA) vs официальный портал (официальные тексты — не объект АП) |

## 3. Решения владельца (зафиксированы 2026-08-31/09-01)

1. `npa-*` модули/крейты — **в этом workspace**; извлечение в отдельный
   Apache-2.0 крейт — зарезервировано, не выполнено.
2. Морфология/лемма — **отложена** до стабильности ссылок и структуры
   (сначала адресация нормы).
3. Источник золотых фикстур — **официальный API/RSS pravo.gov.ru**
   (закупка не требуется); скачивание — с паузами и локальным кэшем.

## 4. Разрывы морфологии (найденные, не исправленные — продуктовая волна)

| Единица | Формы в свободном тексте | Статус |
|---|---|---|
| статья | 8 словоформ (все падежи ед.ч. + мн.ч. И./В./П., ё/е) | ✅ покрыто |
| пункт | 10 словоформ | ✅ покрыто |
| глава / часть / подпункт / раздел | 0 форм | ❌ продуктовый разрыв (ловится только как заголовок лестницей) |

Иерархическая лестница (M171) покрывает заголовки — расширению подлежат
только meta-узлы (преамбула/приложения/подписи), не замена.
